# Telegram AI Bot 🤖

Ek AI-powered Telegram bot jo Groq, SerpApi aur Pixabay ka use karke smart replies deta hai.

## ✨ Features
- AI-generated messages (Groq API se)
- Web search results (SerpApi se)
- Images fetch karna (Pixabay se)
- Trending topics dikhana

## 🛠️ Tech Stack
- JavaScript
- Node.js
- Telegram Bot API

(yahan video/screenshot add karenge — niche dekho)

## 🚀 How to Run
1. Repository clone karo
2. `npm install` chalao dependencies ke liye
3. `.env` file mein apni API keys daalo
4. `node post.js` (ya jo bhi main file hai) run karo
